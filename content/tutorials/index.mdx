## 🛠️ Prerequisites

### Development Environment
- **Node.js**: v18.0+ for JavaScript development
- **Java**: JDK 8+ for smart contract development
- **Python**: 3.9+ for scripting and automation
- **Git**: Version control for code management

### TOS Network Setup
- **TOS Wallet**: [Download here](/getting-started/wallet-setup)
- **Testnet Access**: [Testnet guide](/getting-started/network-config)
- **API Keys**: [Developer portal](https://developers.tos.network)
- **Development Tokens**: [Testnet faucet](https://faucet.tos.network)

### Recommended Tools
- **Code Editor**: VS Code with TOS extensions
- **Testing Framework**: TOS Test Suite
- **Block Explorer**: [explorer.tos.network](https://explorer.tos.network)
- **Documentation**: Always available at [docs.tos.network](https://docs.tos.network)
