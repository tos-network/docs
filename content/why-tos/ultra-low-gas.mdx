# Ultra-Low Gas Fees

TOS Network delivers **$0.001 per transfer** - making it 100x cheaper than TRON and BSC, while matching Solana's low costs with additional native features.

## Why Low Gas Matters

Consider a referral distribution scenario:

```
User invests $100
→ Distribute rewards to 10 uplines ($1-10 each)

On TRON:
- 10 transfers × $0.10 = $1.00 gas cost (1% of investment)
- Significant profit erosion for projects

On TOS:
- 1 batch transfer = $0.025 gas cost (0.025%)
- 40x savings with native batch transfer
```

## Anti-Spam Protection

TOS maintains low costs while preventing abuse:

```rust
// Minimum gas price (prevents spam)
pub const MIN_GAS_PRICE: u64 = 1;

// Dynamic pricing during congestion
fn dynamic_gas_price() -> u64 {
    let pending = get_mempool_size();
    let capacity = TARGET_TPS * BLOCK_TIME;

    if pending > capacity * 5 {
        MIN_GAS_PRICE * 5  // 5x during severe congestion
    } else if pending > capacity * 2 {
        MIN_GAS_PRICE * 2  // 2x during moderate congestion
    } else {
        MIN_GAS_PRICE      // Normal pricing
    }
}

// Per-account rate limiting
pub const MAX_GAS_PER_ACCOUNT_PER_SECOND: u64 = 1_000_000;
```
