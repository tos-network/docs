# Building TOS Network from Source

This comprehensive guide covers building TOS Network software from source code. Building from source gives you access to the latest features, allows customization, and provides deeper understanding of the TOS Network architecture.

## Why Build from Source?

### Benefits
- 🚀 **Latest Features**: Access cutting-edge developments before official releases
- 🔧 **Customization**: Modify code for specific requirements
- 🐛 **Bug Fixes**: Apply patches and fixes immediately
- 📚 **Learning**: Understand TOS Network internals
- ⚡ **Performance**: Optimize builds for your specific hardware
- 🔒 **Security**: Verify code integrity and build reproducibly

### When to Build from Source
- **Development**: Contributing to TOS Network or building applications
- **Research**: Academic or commercial research projects
- **Custom Features**: Need modifications not available in releases
- **Latest Updates**: Want immediate access to new features
- **Security Auditing**: Need to verify every line of code

## Prerequisites

### System Requirements

#### Minimum Requirements
- **CPU**: 4 cores, 2.4GHz
- **RAM**: 8GB (16GB recommended for parallel builds)
- **Storage**: 20GB free space for build artifacts
- **Network**: Stable internet connection for dependencies

#### Recommended Requirements
- **CPU**: 8+ cores, 3.0GHz+
- **RAM**: 16GB+ for faster compilation
- **Storage**: 50GB+ SSD for optimal build speed
- **Network**: High-speed connection for large repositories

### Development Tools

#### Linux (Ubuntu/Debian)
```bash
# Update system
sudo apt update && sudo apt upgrade -y

# Install build essentials
sudo apt install -y \
    build-essential \
    git \
    curl \
    wget \
    cmake \
    pkg-config \
    libssl-dev \
    libclang-dev \
    protobuf-compiler

# Install Go (latest version)
GO_VERSION="1.21.0"
wget https://go.dev/dl/go${GO_VERSION}.linux-amd64.tar.gz
sudo rm -rf /usr/local/go
sudo tar -C /usr/local -xzf go${GO_VERSION}.linux-amd64.tar.gz
echo 'export PATH=$PATH:/usr/local/go/bin' >> ~/.bashrc
source ~/.bashrc

# Install Rust (latest stable)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
source ~/.cargo/env

# Install Node.js (for frontend tools)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# Verify installations
go version      # Should show Go 1.21+
rustc --version # Should show Rust 1.70+
node --version  # Should show Node 20+
npm --version   # Should show npm 10+
```

```bash
    cd $repo
    git status
    git log --oneline -5
    cd ..
done
```

## Building TOS Core

### Core Daemon Build

```bash
cd ~/tos-workspace/tos-core

# Check dependencies
make check-deps

# Download Go dependencies
go mod download
go mod verify

# Build daemon
make build-daemon

# Or build with optimizations
make build-daemon-optimized

# Build output
ls -la build/
# Should show: tos-daemon, tos-daemon-debug

# Install locally
sudo make install-daemon

# Verify build
./build/tos-daemon --version
./build/tos-daemon --help
```

### Advanced Build Options

```bash
# Development build with debug symbols
make build-daemon-debug

# Static build (no dynamic dependencies)
make build-daemon-static

# Cross-compilation builds
make build-daemon-linux-amd64
make build-daemon-linux-arm64
make build-daemon-darwin-amd64
make build-daemon-darwin-arm64
make build-daemon-windows-amd64

# Experimental features
make build-daemon-experimental

# Custom build with specific tags
go build -tags "jsoniter,opencensus" \
    -ldflags "-X main.version=custom-build" \
    -o tos-daemon-custom \
    ./cmd/daemon
```

### Build Configuration

Create `build.config`:

```bash
# Build configuration file
export CGO_ENABLED=1
export GOOS=linux
export GOARCH=amd64
export GO111MODULE=on

# Optimization flags
export GOFLAGS="-mod=readonly"
export LDFLAGS="-s -w -extldflags '-static'"

# Feature flags
export BUILD_TAGS="jsoniter,opencensus,netgo"

# Performance tuning
export GOMAXPROCS=8
export GOCACHE="/tmp/go-build-cache"
```

Source configuration:
```bash
source build.config
make build-daemon
```

## Build Optimization

### Parallel Builds

```bash
# Set build parallelism
export MAKEFLAGS="-j$(nproc)"  # Linux
export MAKEFLAGS="-j$(sysctl -n hw.ncpu)"  # macOS

# Rust parallel compilation
export CARGO_BUILD_JOBS=$(nproc)

# Go parallel compilation
export GOMAXPROCS=$(nproc)

# Build all components in parallel
make -j$(nproc) all
```

### Build Caching

```bash
# Enable Go build cache
export GOCACHE="$HOME/.cache/go-build"

# Enable Rust incremental compilation
export CARGO_INCREMENTAL=1
export CARGO_TARGET_DIR="$HOME/.cache/cargo-target"

# Enable ccache for C/C++ compilation
export CC="ccache gcc"
export CXX="ccache g++"
```

### Memory Optimization

```bash
# Limit memory usage for large builds
export GOGC=50  # More aggressive Go garbage collection
export CARGO_BUILD_JOBS=4  # Limit Rust parallel jobs

# Use swap for large builds
sudo swapon --show
sudo fallocate -l 8G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
```

## Custom Builds

### Feature Flags

```bash
# Build with specific features
go build -tags "jsoniter,netgo,osusergo" ./cmd/daemon

# Rust feature flags
cargo build --features "gpu-mining,ai-processing,experimental"

# Conditional compilation
#[cfg(feature = "gpu-mining")]
fn enable_gpu_mining() {
    // GPU mining code
}
```

### Build Scripts

Create `custom-build.sh`:

```bash
#!/bin/bash
# Custom build script

set -e

echo "Starting custom TOS Network build..."

# Configuration
export BUILD_VERSION="custom-$(date +%Y%m%d)"
export BUILD_FEATURES="gpu-mining,ai-processing"
export OPTIMIZATION_LEVEL="3"

# Clean previous builds
make clean

# Build components
echo "Building daemon..."
make build-daemon FEATURES="$BUILD_FEATURES" VERSION="$BUILD_VERSION"

echo "Building wallet..."
make build-wallet FEATURES="$BUILD_FEATURES" VERSION="$BUILD_VERSION"

echo "Building miner..."
make build-miner FEATURES="$BUILD_FEATURES" VERSION="$BUILD_VERSION"

# Run tests
echo "Running tests..."
make test-quick

# Package builds
echo "Packaging builds..."
tar -czf "tos-custom-${BUILD_VERSION}.tar.gz" build/

echo "Custom build completed: tos-custom-${BUILD_VERSION}.tar.gz"
```

### Cross-Platform Builds

```bash
# Build for multiple platforms
#!/bin/bash

PLATFORMS=(
    "linux/amd64"
    "linux/arm64"
    "darwin/amd64"
    "darwin/arm64"
    "windows/amd64"
)

for platform in "${PLATFORMS[@]}"; do
    GOOS=${platform%/*}
    GOARCH=${platform#*/}

    echo "Building for $GOOS/$GOARCH..."

    GOOS=$GOOS GOARCH=$GOARCH go build \
        -o "build/tos-daemon-$GOOS-$GOARCH" \
        ./cmd/daemon
done
```

## Troubleshooting Build Issues

### Common Build Errors

#### Go Module Issues
```bash
# Clean module cache
go clean -modcache

# Download fresh dependencies
go mod download
go mod verify

# Update dependencies
go get -u ./...
go mod tidy
```

#### Rust Compilation Issues
```bash
# Clean Rust cache
cargo clean

# Update Rust toolchain
rustup update

# Check for missing system dependencies
cargo check

# Force rebuild
cargo build --release --force-rebuild
```

#### Memory Issues
```bash
# Reduce parallel jobs
export MAKEFLAGS="-j2"
export CARGO_BUILD_JOBS=2

# Increase swap space
sudo fallocate -l 4G /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
```

#### Permission Issues
```bash
# Fix ownership
sudo chown -R $USER:$USER ~/tos-workspace

# Fix permissions
chmod -R 755 ~/tos-workspace

# Use proper directories
export GOPATH="$HOME/go"
export CARGO_HOME="$HOME/.cargo"
```

### Debugging Build Issues

```bash
# Verbose build output
make build-daemon VERBOSE=1

# Go build with verbose output
go build -v -x ./cmd/daemon

# Rust build with verbose output
cargo build --verbose

# Check system dependencies
ldd build/tos-daemon  # Linux
otool -L build/tos-daemon  # macOS

# Check for missing libraries
ldconfig -p | grep ssl
pkg-config --list-all
```

### Continuous Development

```bash
# Watch for changes and rebuild
while inotifywait -e modify src/; do
    make build-daemon-debug
done

# Auto-restart during development
while true; do
    ./build/tos-daemon-debug --dev &
    PID=$!
    inotifywait -e modify build/tos-daemon-debug
    kill $PID
    make build-daemon-debug
done
```
