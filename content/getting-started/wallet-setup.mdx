# Setting Up Your TOS Wallet

- 🔒 **Encrypted Balances**: Your balance is never visible to anyone except you

- 🔐 **Zero-Knowledge Security**: Mathematical proofs protect your privacy
- ⚡ **Energy Integration**: Stake TOS for gas-free transactions

## Step 1: Download and Install

### Desktop Installation

- **Download the Wallet**
   ```bash
   # For Linux users, you can also use:
   wget https://releases.tos.network/wallet/linux/tos-wallet-latest.AppImage
   chmod +x tos-wallet-latest.AppImage
   ./tos-wallet-latest.AppImage
   ```

2. **Verify the Download** (Recommended)
   ```bash
   # Verify the cryptographic signature
   gpg --verify tos-wallet-latest.AppImage.sig tos-wallet-latest.AppImage

   # Check SHA256 hash
   sha256sum tos-wallet-latest.AppImage
   # Compare with published hash on releases page
   ```

3. **Install and Launch**
   - Run the installer
   - Follow the setup wizard
   - Launch TOS Wallet

### Mobile Installation

## Step 2: Create Your First Wallet

### New Wallet Creation

- **Launch TOS Wallet**
2. **Select "Create New Wallet"**
3. **Choose Wallet Type:**
   - **Standard Wallet**: Full privacy features (recommended)
   - **Watching Wallet**: View-only for monitoring
   - **Multi-Signature Wallet**: Enhanced security for organizations

4. **Set Wallet Name**
   ```
   Example: "My TOS Wallet"
   ```

5. **Create Strong Password**
   - Minimum 12 characters
   - Include uppercase, lowercase, numbers, symbols
   - Use a password manager
   - Write it down securely

### Seed Phrase Generation

**Critical Security Step: Your seed phrase is the master key to your wallet**

- **Generate Seed Phrase**
   - Wallet will generate 24-word recovery phrase
   - Each word is from the BIP39 standard wordlist
   - Example: `abandon ability able about above absent absorb abstract...`

2. **Write Down Your Seed Phrase**
   ```
   🚨 CRITICAL: Write this down on paper, never store digitally

   Word 1:  _________    Word 13: _________
   Word 2:  _________    Word 14: _________
   Word 3:  _________    Word 15: _________
   ...and so on for all 24 words
   ```

3. **Verify Your Seed Phrase**
   - Wallet will ask you to confirm words in random order
   - This ensures you wrote them down correctly

4. **Store Securely**
   - Keep in fireproof safe
   - Consider multiple copies in different locations
   - Never photograph or store digitally
   - Consider metal backup plates for long-term storage

## Step 6: Making Your First Transaction

### Understanding TOS Transactions

TOS transactions are **completely private**:

- ✅ Amounts are encrypted
- ✅ Balances remain hidden
- ✅ Zero-knowledge proofs validate without revealing
- ✅ Network cannot see transaction values

### Sending TOS

- **Click "Send"**
2. **Enter Recipient Address**
   ```
   Recipient: tos1def456ghi789jkl012mno345pqr678stu901vwx234...
   ```

3. **Enter Amount**
   ```
   Amount: 100 TOS
   Note: This amount will be encrypted before sending
   ```

4. **Choose Fee Payment Method**
   - **Gas Fees**: Pay with TOS (traditional)
   - **Energy**: Use staked TOS energy (gas-free)

5. **Review and Confirm**
   ```
   Transaction Summary:
   ├── To: tos1def456ghi789jkl012mno345pqr678stu901vwx234...
   ├── Amount: ██████ TOS (encrypted)
   ├── Fee: 0.0001 TOS (or Energy)
   └── Privacy: Maximum (default)
   ```

6. **Authorize Transaction**
   - Enter wallet password
   - Confirm with 2FA if enabled
   - Transaction is broadcast privately

### Transaction Confirmation

## Troubleshooting

### Common Issues

#### Wallet Won't Sync

```bash
# Check network connection
ping explorer.tos.network

# Reset wallet sync
Settings → Advanced → Reset Sync

# Check firewall settings
Allow port 2080 for TOS Network
```

#### Transaction Stuck

```bash
# Check transaction status
View transaction in explorer: https://explorer.tos.network

# Increase fee if necessary
Create new transaction with higher fee

# Contact support if issue persists
Email: support@tos.network
```

#### Lost Access

```bash
# Restore from seed phrase
1. Install wallet on new device
2. Select "Restore Wallet"
3. Enter 24-word seed phrase
4. Set new password
5. Wait for sync completion
```
