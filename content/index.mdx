# TOS Network - OpenSystem Network

## 🛡️ The Indestructible Topology

**OpenSystem Network** embodies the fusion of mathematical topology and Spartan resilience. Like ancient Spartan warriors who formed impenetrable phalanx formations where each soldier's shield protected their neighbor, our network creates a **decentralized fortress** where each node validates and shields others.

**TOS** is the world's first BlockDAG with Privacy, Scalability, and Smart Contracts - guided by the principle **"Don't Trust, Verify it"**.

Built from scratch with a focus on trustless verification, scalability, and decentralized consensus,
OpenSystem Network is a decentralized blockchain that eliminates trust through cryptographic proof and verification—creating an indestructible distributed system that is both **scientifically robust** and **strategically resilient**.

The project embodies the fundamental blockchain principle that **trust should be eliminated through verification**. Every aspect of the system—from transactions and balances to mining rewards and smart contract execution—provides cryptographic proof rather than requiring trust in centralized authorities.

To achieve this, TOS has implemented innovative features including:
- **TAKO Smart Contracts** - Rust-based smart contracts with eBPF-inspired runtime
- **Ultra-Low Gas** - $0.001 per transaction, 100x cheaper than competitors
- **1-Second Finality** - Fastest confirmation in the industry
- **Native Privacy (UNO)** - Protocol-level encrypted transfers
- **Native Features** - VRF randomness, referral system, batch transfers, scheduled tasks
- **BlockDAG architecture** with enhanced scalability and security
- **Homomorphic Encryption** and **Zero-Knowledge Proofs** for complete privacy
- **TOS Energy Model (TEM)** - Stake-to-earn energy for gas-free transactions

Built using Rust throughout the stack and powered by Tokio async runtime, TOS is designed to be fast, efficient, and secure.

All networks have the exact same consensus rules, but do not share the same chain or peers.

## Consensus Configuration

The current configuration of the consensus is:
- Target Block Time: `15` seconds
- Minimum transaction fee: `0.00001000` TOS per KB
- Full coin divisibility: `8` decimals
- Maximum supply: `18.4` million TOS
- Maximum block size: `1.25` MB
- Maximum transaction size: `1` MB

To prevent address misuse across different networks, we set prefixes:
- Mainnet addresses begin with `tos` prefix
- Devnet/testnet addresses begin with `tst` prefix

## Core Objectives

### Privacy Through Trustless Verification
We provide better **privacy** than Bitcoin and Ethereum through encrypted balances and transferred amounts.
This is achieved using [Homomorphic Encryption](/features/privacy/homomorphic-encryption) and [Zero-Knowledge Proof](/features/privacy/zero-knowledge-proof).
Nobody except you can see how much you own and how much you spend - all verified cryptographically.

### Scalability & Security
**Scalability** and **security** are addressed using our [BlockDAG](/features/scalability/blockdag) architecture.
With a low block time target, we minimize orphaned blocks through BlockDAG, allowing higher block count, faster confirmation, better security, and more transactions per second.

### Smart Contracts with TAKO
[Smart Contracts](/smart-contracts) are powered by **TAKO**, our eBPF-inspired smart contract runtime.
Write contracts in Rust using the `tako_sdk` crate, with access to native features like VRF randomness, referral rewards, and batch transfers.

### Confidential Assets & DeFi
[Confidential Assets](/features/privacy/confidential-assets) allow creation of truly decentralized tokens with the same level of privacy and decentralization as TOS.
These aren't just Smart Contract numbers but native blockchain assets with full privacy features.

### Decentralized Network
**Decentralization** is ensured through widespread node distribution and democratized mining.
Our ASIC-resistant algorithm makes participation accessible to everyone.

### Ease of Use
**Ease of use** is fundamental for real adoption in daily usage.
This applies to both end users and developers creating applications on TOS Network.

## TOS Energy Model (TEM)

TOS introduces a revolutionary **TOS Energy Model** that allows users to stake TOS tokens to generate "Energy" for gas-free transactions:

- **Flexible Staking**: 7-365 day lock periods with dynamic energy generation
- **Gas-Free Transactions**: Use Energy instead of paying transaction fees
- **Cost Predictability**: Predictable transaction costs for active users
- **Network Stability**: Reduces circulating supply and promotes long-term holding
- **Trustless Verification**: All staking and energy calculations are cryptographically verifiable

## Funding & Development

TOS Network is a community-driven project committed to decentralization and trustless verification.
Development is supported through a transparent and decreasing dev fee structure:

- **10%** from block 0 to 3,249,999 (approximately 1.5 years with BlockDAG)
- **5%** from block 3,250,000 until the ecosystem reaches stability

The funds are exclusively used for network development, ecosystem growth, and ensuring continuous innovation.
The community participates in decisions about fund allocation through transparent governance.

All fee mechanisms will transition to Smart Contract-based DAO governance once our Smart Contract capabilities are fully deployed, ensuring complete trustless management following our core principle: **"Don't Trust, Verify it"**.
