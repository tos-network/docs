### Addresses and Transactions

**Q: Why does my TOS address change after each transaction?**

A: TOS Network uses one-time addresses for maximum privacy:
- **Privacy Protection**: Prevents transaction correlation and address clustering
- **Automatic Generation**: Wallet automatically generates new addresses
- **All Valid**: Previous addresses still work for receiving funds
- **Viewing Keys**: You can still see all transactions in your wallet

**Q: Can I reuse TOS addresses?**

A: While technically possible, it's not recommended:
- **Privacy Loss**: Reusing addresses reduces privacy protection
- **Best Practice**: Use new address for each transaction
- **Wallet Automation**: Modern wallets handle this automatically
- **Exception**: Some applications may require static addresses

**Q: Why are TOS transactions taking a long time to confirm?**

A: Several factors can affect confirmation times:

**Network Factors:**
- **Congestion**: High network usage increases confirmation times
- **Fee Level**: Higher fees get priority inclusion
- **Block Time**: TOS targets 15-second blocks but can vary

**Solutions:**
- Use higher transaction fees during congestion
- Switch to energy payments (unaffected by congestion)
- Wait for network congestion to reduce
- Check network status at status.tos.network

## Energy Model

### Understanding Energy

**Q: What is the TOS Energy Model?**

A: The Energy Model enables gas-free transactions through staking:

**How It Works:**
- **Stake TOS Tokens**: Lock TOS for a specified period
2. **Generate Energy**: Staked TOS automatically generates energy units
3. **Use Energy**: Pay transaction fees with energy instead of TOS tokens
4. **Predictable Costs**: Energy costs are independent of network congestion

**Benefits:**
- Gas-free transactions
- Predictable transaction costs
- Protection from fee spikes
- Sustainable transaction model

**Q: How much TOS should I stake for energy?**

A: Staking recommendations based on usage:

**Light User (1-10 transactions/month):**
- Stake: 100-500 TOS
- Energy Generation: ~50-250 units/day
- Covers: Basic transaction needs

**Regular User (50+ transactions/month):**
- Stake: 1,000-5,000 TOS
- Energy Generation: ~500-2,500 units/day
- Covers: Regular transaction activity

**Heavy User/Business (100+ transactions/day):**
- Stake: 10,000+ TOS
- Energy Generation: ~5,000+ units/day
- Covers: High-volume transaction needs

**Q: Can I unstake my TOS at any time?**

A: Staking has lock periods for network stability:
- **Lock Periods**: 7 days (minimum) to 365 days (maximum)
- **Longer Locks**: Higher energy generation rates
- **Early Unstaking**: Generally not permitted during lock period
- **Automatic Renewal**: Can be configured for convenience

## Troubleshooting

### Common Issues

**Q: My wallet won't sync. What should I do?**

A: Try these solutions in order:

**1. Check Network Connection:**
```bash
ping explorer.tos.network
```

**2. Restart Wallet:**
- Close wallet completely
- Wait 30 seconds
- Restart wallet

**3. Check Firewall:**
- Allow TOS wallet through firewall
- Ensure ports 2080 and 8080 are open

**4. Reset Sync Data:**
- Backup wallet first
- Reset blockchain sync data
- Resync from network

**5. Contact Support:**
- Join Discord for real-time help
- Email support@tos.network

**Q: My transaction is stuck. How can I fix it?**

A: Stuck transaction solutions:

**Check Transaction Status:**
- Use blockchain explorer
- Verify transaction was broadcast
- Check confirmation count

**Low Fee Solutions:**
- Wait for network congestion to reduce
- Use replace-by-fee if supported
- Create new transaction with higher fee

**Energy Transactions:**
- Verify sufficient energy balance
- Check energy generation rate
- Consider staking more TOS

**Q: I lost my seed phrase. Can I recover my wallet?**

A: Seed phrase recovery options:

**If You Have Access to Open Wallet:**
- Export private keys immediately
- Create new wallet with new seed phrase
- Transfer funds to new wallet

**If Wallet is Locked:**
- Check for any backup files
- Look for password manager entries
- Check for written copies in secure locations

**Prevention for Future:**
- Write seed phrase on paper
- Store in multiple secure locations
- Consider metal backup plates
- Never store digitally
